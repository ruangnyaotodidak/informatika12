Pengenalan Web & HTML

A. Sejarah World Wide Web

1. Pencipta WWW

World Wide Web (WWW) diciptakan oleh Sir Tim Berners-Lee pada tahun 1989 di CERN (Organisasi Eropa untuk Riset Nuklir) yang berlokasi di Jenewa, Swiss. Awalnya, WWW dirancang untuk memudahkan pertukaran dokumen ilmiah antar peneliti di berbagai negara.

Pada tanggal 6 Agustus 1991, Tim Berners-Lee mempublikasikan website pertama di dunia. Sejak saat itu, web berkembang pesat menjadi medium informasi terbesar di dunia dengan lebih dari 1,9 miliar website aktif (data Statista, 2025).

Web ini untuk semua orang. Ia harus dapat diakses oleh siapa saja, di mana saja, dan dari perangkat apa saja.

— Tim Berners-Lee

B. Cara Kerja Browser dan Web

1. Apa Itu Browser?

Browser (peramban) adalah aplikasi yang digunakan untuk mengakses dan menampilkan halaman web. Contoh browser populer: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari.

2. Cara Kerja Browser

💡 Alur Sederhana Saat Membuka Website
  1. User mengetik alamat website (URL) di browser, misal: https://masdinilimojurai.sch.id
  2. Browser mengirim permintaan (request) ke server melalui internet
  3. Server menerima permintaan dan mencari file HTML yang diminta
  4. Server mengirim file HTML kembali ke browser (response)
  5. Browser membaca kode HTML dan menampilkannya sebagai halaman web yang bisa dibaca manusia
🌿 Analogi Sederhana

Bayangkan browser seperti pelayan restoran: Anda (user) memesan makanan (URL), pelayan (browser) menyampaikan pesanan ke dapur (server), dapur menyiapkan makanan (file HTML), dan pelayan menghidangkannya kepada Anda (halaman web tampil).

C. Pengenalan HTML

1. Apa Itu HTML?

HTML singkatan dari HyperText Markup Language — bahasa penanda (markup language) standar untuk menyusun struktur halaman web.

Penting untuk dipahami: HTML BUKAN bahasa pemrograman. HTML tidak memiliki logika percabangan (if-else) atau perulangan (loop). HTML hanya berfungsi sebagai "kerangka" atau "tulang punggung" sebuah situs web — mendefinisikan apa yang ditampilkan dan bagaimana kontennya terstruktur.

D. Prinsip Belajar Web di Madrasah

Di MAS Diniyah Limo Jurai, belajar HTML bukan sekadar keterampilan teknis. Setiap halaman web yang dibuat harus memenuhi prinsip berikut:

📋 Empat Prinsip Utama
  1. Bermanfaat: Konten memberikan ilmu, inspirasi, atau kemudahan bagi pembaca
  2. Mudah Diakses: Semua orang bisa membaca, termasuk penyandang disabilitas (gunakan alt text, kontras warna yang baik)
  3. Sopan & Santun: Bahasa yang digunakan menghormati pembaca, tidak provokatif, tidak menyinggung
  4. Menyebarkan Kebaikan: Konten mengajak pada hal positif, ilmu yang bermanfaat, dan akhlak mulia
🌿 Nilai: Aksesibilitas sebagai Bentuk Kebaikan

Selalu cantumkan atribut alt pada gambar. Mengapa? Karena ada saudara kita yang menggunakan screen reader (pembaca layar) karena keterbatasan penglihatan. Dengan alt text, mereka tetap bisa "membaca" gambar melalui deskripsi audio. Ini adalah bentuk kepedulian dan kasih sayang terhadap sesama — memastikan ilmu dan informasi bisa dinikmati semua orang tanpa terkecuali.

E. Nilai Karakter dalam Pembuatan Web

🌿 Tanggung Jawab, Kejujuran, dan Kepedulian

Membuat halaman web yang baik melatih tiga nilai karakter penting:

  • Tanggung Jawab: Menyajikan informasi yang benar, tidak menyebarkan hoaks atau konten negatif
  • Kejujuran: Tidak meniru karya orang lain tanpa izin (hak cipta), mencantumkan sumber dengan benar
  • Kepedulian: Membuat web yang bisa diakses semua orang, termasuk penyandang disabilitas

Cukuplah seseorang dikatakan pendusta jika ia menceritakan semua yang didengarnya (tanpa verifikasi).

— HR. Muslim

Hadits ini sangat relevan dengan pembuatan konten web. Seorang siswa yang membuat halaman web harus memastikan informasi yang disebarkan adalah benar dan dapat dipertanggungjawabkan. Menyebarkan hoaks atau informasi palsu melalui web adalah bentuk kedustaan yang akan dipertanggungjawabkan di akhirat.

G. Tugas Praktik

📋 Tugas Individu (Dikumpulkan Pertemuan Berikutnya)
  1. Buatlah mind map tentang "Sejarah World Wide Web" yang mencakup: pencipta, tahun, tempat, tujuan awal, dan perkembangan hingga sekarang. Gunakan kertas A4 atau aplikasi mind mapping!
  2. Tuliskan alur kerja browser saat membuka website dalam bentuk diagram alir sederhana. Gunakan analogi yang mudah dipahami (misal: analogi restoran seperti di materi)!
  3. Buatlah daftar 5 website madrasah/sekolah Islam yang kamu kunjungi. Analisis masing-masing: apakah kontennya bermanfaat? mudah diakses? sopan? Tuliskan dalam tabel!
  4. Coba buka Notepad (Windows) atau TextEdit (Mac), ketik kode HTML sederhana berikut, simpan dengan nama halaman-pertamaku.html, lalu buka di browser: 
    <!DOCTYPE html>
<html>
<head><title>Halaman Pertamaku</title></head>
<body>
<h1>Assalamu'alaikum!</h1>
<p>Ini adalah halaman web pertamaku.</p>
</body>
</html>
  5. Refleksi: Tuliskan 1 paragraf tentang bagaimana pembelajaran web hari ini dapat kamu terapkan untuk menyebarkan kebaikan di era digital!
